# RunWeave 开发文档

状态：生效。更新日期：2026-09-10。维护责任：当前工作项开发者；阶段收尾由项目维护者核对。

本目录保存随代码持续维护的开发文档，正文统一使用简体中文。根目录既有文档属于总体规划，作为范围和历史背景引用，不计入本目录的开发文档体系。

## 从这里开始

| 文档 | 用途 |
| --- | --- |
| [开发文档维护规范](开发文档维护规范.md) | 文档触发条件、阶段要求、写作标准和完成检查 |
| [开发进度](进度/开发进度.md) | 当前已实现/已验证范围、未完成项和下一步 |

开发前先检查规范和本次工作相关文档；交付时更新受影响的文档与索引。按真实需要创建文档，不提前创建空目录、空模板或尚未实现功能的使用说明。

## 内容落点

以下为约定落点，不代表这些目录或文档已经存在。

| 目录 | 内容 |
| --- | --- |
| `设计/` | 当前架构、模块职责、执行语义、设计方案与实现差异 |
| `决策/` | 有编号的架构决策记录（ADR） |
| `参考/` | MCP 工具、HTTP API、Node 协议、配置、错误码、存储 schema |
| `指南/` | 环境准备、开发、调试、安装、接入、迁移、备份恢复和排障步骤 |
| `验证/` | 测试策略、技术验证、客户端兼容、故障注入和阶段验收证据 |
| `进度/` | 当前工作项状态、阶段门槛和待办 |
| `发布/` | 面向使用者的变更记录、发布说明与兼容性说明 |
| `资源/` | 文档引用的图、脱敏样例和必要的小型证据文件 |
