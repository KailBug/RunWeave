# ADR 0001：P0 基础依赖与实验边界

状态：已接受。日期：2026-09-10。适用范围：P0-01 / Go 1.27.0。维护责任：当前工作项开发者。

## 背景与决定

按[三个月规划](../../RunWeave3个月开发规划书.md)验证无 CGO 的 Linux 构建，使用 database/sql + `modernc.org/sqlite v1.58.0`、`github.com/coder/websocket v1.8.15`、`go.yaml.in/yaml/v3 v3.0.5`。MCP 保留官方 SDK v1.7.0。版本由 Go module 查询获得并固定，不自动跟随 latest。

SQLite 的备选是需要 C 工具链的驱动；当前优先纯 Go，接受较大的构建与依赖体积。WebSocket 使用独立库而不自写协议；选择具备 context、消息限额和明确关闭接口的 coder/websocket。YAML 使用 yaml 组织维护的 v3 分支，避免本阶段迁移至新主版本；严格字段检查之外仍需应用层限制文档数和配置版本。

依据：[SQLite 驱动](https://pkg.go.dev/modernc.org/sqlite)、[WebSocket](https://github.com/coder/websocket)、[YAML](https://pkg.go.dev/go.yaml.in/yaml/v3)。精确依赖以 [go.mod](../../go.mod) 为准。

## 实现前的实验范围与出口

在 `tests/p0` 建立隔离实验，使用临时数据库、loopback HTTP 测试服务器和测试专用 Linux 子进程。不会新增正式 Server/Node 或远程执行入口。

- SQLite：WAL、外键、busy_timeout；事务迁移成功与失败回滚；关闭重开后的数据与迁移版本；唯一约束。实验单连接，不作为并发写入或灾难恢复验收。
- WebSocket：实际连接、UTF-8 回显、1 MiB 消息限制、对端断线与读取 deadline。生产单写循环、身份、epoch 与重连由后续阶段实现。
- YAML：合法配置、未知字段、重复键、多文档、错误版本被拒；仅测试配置样例，不冻结正式配置字段。
- Linux：独立进程组；TERM 正常退出与忽略 TERM 后 KILL；真实后代回收及输出管道结束。仅支持受管理前台作业，不承诺处理 setsid 逃逸或 daemon 崩溃恢复。

以上通过仅满足 P0-01 技术实验部分；外部客户端历史证据与本次结果分别记录，P0-02/03 仍需独立完成。

实现见 [P0 实验](../../tests/p0/dependencies_test.go)，复现与结果见 [本次验证](../验证/2026-09-10-P0基础依赖与进程验证.md)。
