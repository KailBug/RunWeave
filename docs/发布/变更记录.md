## 未发布

### 新增

- P1 首批统一 `runweave` CLI：版本查询、严格 YAML 配置预检、Server/Node 状态初始化；命令结果与诊断分离，配置不接受内联 token。
- 分角色 SQLite 初始迁移、持久实例身份、状态目录 OS 独占锁、启动写入检查与停机恢复检查。旧版本或迁移历史不匹配时拒绝打开，不自动降级。
- Server HTTP/TLS daemon，独立 principal/Node 身份创建、在线撤销和认证检查；原始凭据限权文件，库中只存摘要。Server 升级至 schema v2，Node 保持 v1。
- `server serve`、`identity create/revoke`、`auth check`，以及可选客户端 `tls_ca_file`。新增身份检查端点；`/readyz` 在执行服务完成前持续 503，认证成功不代表可调度。

当前尚无 Node daemon/注册、远程文件操作或 MCP 业务链路。身份撤销不可恢复，原 ID 不可重建；旧版本库备份恢复须重新核对撤销事实。操作与兼容范围见[接入指南](../指南/P1身份接入与Server运行.md)，Windows/WSL 与 race 实际结果见[第二批验证](../验证/2026-09-14-P1身份与Server验证.md)。
