## 复现

PowerShell，工作目录为仓库根目录，需要 Go 1.27.0。缓存位于被忽略的 `.cache/`；测试仅读样例，不访问真实 Node 或用户资源。本项不需要模型/外部客户端。

```powershell
$env:GOPATH = "$PWD/.cache/gopath"
$env:GOMODCACHE = "$PWD/.cache/gomod"
$env:GOCACHE = "$PWD/.cache/gobuild"
go test ./... -count=1
go test -race ./... -count=1
go vet ./...
go test ./internal/contract '-run=^$' '-fuzz=^FuzzRequestRoundTrip$' '-fuzztime=10s' '-parallel=1'
go test ./internal/contract '-run=^$' '-fuzz=^FuzzResultRoundTrip$' '-fuzztime=10s' '-parallel=1'
go run golang.org/x/vuln/cmd/govulncheck@v1.8.0 -test ./...
```

另一 PowerShell 会话中设置相同缓存变量，再执行 Linux 验证；必须设置工作目录到包目录，以便测试读取同一套 docs fixtures：

```powershell
$env:GOOS = 'linux'
$env:GOARCH = 'amd64'
$env:CGO_ENABLED = '0'
go test -c -o bin/contract-linux-amd64.test ./internal/contract
go vet ./...
wsl -d Ubuntu --cd /mnt/d/RunWeave/internal/contract --exec /mnt/d/RunWeave/bin/contract-linux-amd64.test '-test.v' '-test.timeout=45s'
```

逐条核对退出码。短时 fuzz 只能说明本次样本未发现失败，不能宣称穷尽输入或安全审计通过。
