## 实现与实际验证

| 对象 | 实际证据 |
| --- | --- |
| [生命周期函数](../../internal/contract/lifecycle.go)及[测试](../../internal/contract/lifecycle_test.go) | 接收→审批→断线→取消→启动承诺→运行→自然成功链路，保留取消意图；审批与 UNKNOWN 持续占槽 |
| 迟到、重复与冲突 | 低 revision 不回退；同 revision 异内容拒绝更新；已知终态同摘要为重复、异摘要为冲突；相同 snapshot 可恢复断线未知，普通重复通知不恢复 |
| 模糊启动与重启 | START_COMMITTED→UNKNOWN；确证启动失败可 FAILED；UNRESOLVED 保留已知 started，不释放槽位、不回退接收、不重新派发 |
| 终态约束 | 未确认 quiescent、uncertain 启动事实、状态/错误码不符、未启动却已有正文/输出均拒绝；可信终态可直接跳过中间通知 |
| 本地取消 | 仅 CREATED 且有取消意图可本地 CANCELLED，已经可能派发的记录不能本地确认停止 |
| [协议 Codec](../../internal/protocol/protocol.go)及[测试](../../internal/protocol/protocol_test.go) | [17 个 JSON 样例](../资源/Node协议/消息样例.json)：14 类合法消息和 3 个非法例逐条验证；重编码稳定 |
| 协议负例 | 错方向、旧/缺 epoch、伪造注册 Node、未知版本/字段/类型、重复键、null、错误摘要/phase、混合产物成功/错误字段均拒绝 |
| MatchReply | query_message_id、请求摘要、execution/epoch、Outcome 摘要、artifact_id/offset/limit 匹配；格式合法的错误 receipt 摘要仍拒绝 |
| 帧与扩展边界 | 完整帧 1 MiB 边界通过、超一字节拒绝；单扩展 4096 字节边界通过、编码转义后超限也拒绝 |
| [严格 JSON 共享包](../../internal/strictjson/json.go) | P0-02 解码逻辑抽取复用，新增 RawMessage/扩展 map 形状检查；原请求固定摘要向量和全部业务 fixtures 回归通过 |

本次增加 UNRESOLVED 是在实现核对中明确原规划要求的“Node 崩溃后未知/隔离”表达，未改变 UNKNOWN 占槽或禁止盲目重跑的范围。Node 在重启后不能仅凭旧 journal 的 RUNNING 就宣称已重新取得进程管理权。

## 检查命令与结果

PowerShell，仓库根目录；缓存写入被忽略的 `.cache/`。协议/状态测试只读脱敏 fixtures 并运行纯函数；全仓测试还会运行 P0-01 临时数据库和 loopback 实验。没有连接真实 Server/Node 或调用模型。

```powershell
$env:GOPATH = "$PWD/.cache/gopath"
$env:GOMODCACHE = "$PWD/.cache/gomod"
$env:GOCACHE = "$PWD/.cache/gobuild"
go test ./... -count=1
go test -race ./... -count=1
go vet ./...
go test ./internal/protocol '-run=^$' '-fuzz=^FuzzProtocolRoundTrip$' '-fuzztime=10s' '-parallel=1'
go test ./internal/contract '-run=^$' '-fuzz=^FuzzLifecycleEvidence$' '-fuzztime=10s' '-parallel=1'
go run golang.org/x/vuln/cmd/govulncheck@v1.8.0 -test ./...
```

以上全部通过。协议 fuzz 17 个初始种子、443205 次输入、约 10.455 秒；生命周期 fuzz 2 个初始种子、478281 次输入、约 10.557 秒；均为 1 worker、PASS。短时随机输入不等于穷尽验证。

另一个 PowerShell 会话设置相同缓存变量，再执行交叉验证；改变工作目录是为了读取与 Windows 相同的 docs fixtures：

```powershell
$env:GOOS = 'linux'
$env:GOARCH = 'amd64'
$env:CGO_ENABLED = '0'
go test -c -o bin/contract-linux-amd64.test ./internal/contract
go test -c -o bin/protocol-linux-amd64.test ./internal/protocol
go vet ./...
wsl -d Ubuntu --cd /mnt/d/RunWeave/internal/contract --exec /mnt/d/RunWeave/bin/contract-linux-amd64.test '-test.timeout=45s'
wsl -d Ubuntu --cd /mnt/d/RunWeave/internal/protocol --exec /mnt/d/RunWeave/bin/protocol-linux-amd64.test '-test.timeout=45s'
```

Linux 两个测试二进制均输出 PASS，Linux 目标 vet 通过。逐条核对退出码，不用最后一条成功掩盖前面失败。
