## 实际证据

执行方法与完整命令见[复验指南](../指南/P0真实客户端验证.md)，实际提示和两侧事件见[证据目录](../资源/MCP契约/README.md)。CLI 退出码为 0，存在 turn.completed。记录仅提取实际 MCP 完成事件，没有用模型总结生成测试结果。

| 次序 | 工具/场景 | 实际结果 |
| --- | --- | --- |
| 1–2 | list_nodes、list_resources | 返回 p0-simulated-node、repo://p0-fixture 与权限/资源证据字段；没有物理根目录 |
| 3–4 | execute fs.list，同参数重试 | 两次均为 p0-execution-1，同一规范请求摘要；成功终态携带结果、placement 与产物引用 |
| 5 | 同 request_id 改 max_entries | IDEMPOTENCY_CONFLICT，isError=true；未生成新 execution |
| 6 | execute fs.read，limit=4 | p0-execution-2；base64 UnVuVw==，bytes_returned=4，eof=false |
| 7–8 | execute process.exec，再按 request_id 查询 | p0-execution-3，WAITING_APPROVAL，包含 approval、poll_after_ms=100；literal/path 两类参数实际传入，未启动程序 |
| 9 | cancel_execution | 仍 WAITING_APPROVAL，cancel_requested=true；没有终态结果 |
| 10 | 按 execution_id 查询取消确认 | CANCELLED，outcome.start=not_started，quiescent=true，poll_after_ms=0 |
| 11 | 读取第 3 次返回的 artifact_id，limit=4 | p0-artifact，UnVuVw==，4 字节、eof=false |
| 12–13 | 缺失 execution、artifact | EXECUTION_NOT_FOUND、ARTIFACT_NOT_FOUND，均 isError=true |

Codex 将三次预期工具错误标为 `status=failed`，其余 10 次为 completed；服务端的 isError 与结构化 error 相符。每次文本 JSON 和 structuredContent 在解码后相同。`TestRecordedCodexEvidence` 检查全部参数/输出、六个实际发现 schema、请求摘要和关键场景，防止只依赖自然语言结论。

原始 CLI stderr 有模型列表刷新超时、推荐插件目录网络失败和 PowerShell shell snapshot 不支持提示；这些没有阻止 MCP 初始化、13 次调用及 turn.completed。仅记录实际影响，不把附属请求失败扩大为本次契约失败，也不据此宣称所有网络功能可用。

## 自动检查与 Linux 复验

以下均已实际通过，逐条检查退出码：

```powershell
go test ./... -count=1
go test -race ./... -count=1
go vet ./...
./bin/mcp-contract-probe.exe check
go test ./internal/contractprobe -run TestRecordedCodexEvidence -v
```

补充证据测试后重跑全量普通测试、两个新增包 race 与全量 vet，均通过。SDK 自检另覆盖未知字段、null、重复键、非法分页、双查询键、错误后的会话可用性；这些额外非法输入由 SDK 测试完成，未宣称外部模型逐一尝试。合法历史业务 fixtures 被新 schema 接受；发布 schema 与生成器一致，互斥输入/输出联合反例被拒。

Linux 实际步骤（先设置指南中的缓存变量）：

```powershell
$env:GOOS = 'linux'
$env:GOARCH = 'amd64'
go build -o bin/mcp-contract-probe-linux ./cmd/mcp-contract-probe
go test -c -o bin/contractprobe-linux.test ./internal/contractprobe
go test -c -o bin/mcpcontract-linux.test ./internal/mcpcontract
Remove-Item Env:GOOS,Env:GOARCH
wsl --exec /bin/sh -lc 'cd /mnt/d/RunWeave && ./bin/mcp-contract-probe-linux check && cd internal/contractprobe && ../../bin/contractprobe-linux.test -test.v && cd ../mcpcontract && ../../bin/mcpcontract-linux.test -test.v'
```

Linux stdio check、内存会话、schema 和后补的真实证据测试均 PASS。真实外部 Codex 调用只在 Windows 完成，没有测试 Linux Codex 或其他外部客户端。race 在 Windows 执行，未声明 Linux race。
