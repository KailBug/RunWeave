## 复现命令

PowerShell，仓库根目录；逐条检查退出码。

```powershell
$env:GOPATH = "$PWD/.cache/gopath"
$env:GOMODCACHE = "$PWD/.cache/gomod"
$env:GOCACHE = "$PWD/.cache/gobuild"
go test ./... -count=1
go vet ./...
$env:CGO_ENABLED = '1'
go test -race ./... -count=1
go build -o bin/runweave.exe ./cmd/runweave
./docs/资源/P1身份/验证Server身份.ps1
```

产品[脚本](../资源/P1身份/验证Server身份.ps1)实际输出两类身份创建/查询、`revoked:true`，以及 `PASS: 产品 Server、跨进程锁、两类身份接入、在线撤销、stdout 隔离`。结束后产品进程被脚本强制终止，状态初始化仍成功返回 Server schema 2；这是强制退出后的锁释放，不代替优雅关闭测试。脚本使用独立随机测试目录/临时端口，撤销测试身份后保留文件供排查，没有原始 token 输出。

在独立 PowerShell 会话构建并运行 WSL 测试，避免交叉环境影响 Windows 构建：

```powershell
$env:GOPATH = "$PWD/.cache/gopath"
$env:GOMODCACHE = "$PWD/.cache/gomod"
$env:GOCACHE = "$PWD/.cache/gobuild"
$env:GOOS = 'linux'
$env:GOARCH = 'amd64'
$env:CGO_ENABLED = '0'
foreach ($package in @('store','identity','secretfile','server','controlclient','config')) {
    go test -c -o "bin/p1-$package-linux-amd64.test" "./internal/$package"
    if ($LASTEXITCODE -ne 0) { throw '交叉构建失败' }
}
go test -c -o bin/p1-cli-linux-amd64.test ./cmd/runweave
go build -o bin/runweave-linux-amd64 ./cmd/runweave
go vet ./...
foreach ($package in @('store','identity','secretfile','server','controlclient')) {
    wsl -d Ubuntu --exec "/mnt/d/RunWeave/bin/p1-$package-linux-amd64.test" '-test.v' '-test.timeout=60s'
    if ($LASTEXITCODE -ne 0) { throw 'WSL 测试失败' }
}
wsl -d Ubuntu --cd /mnt/d/RunWeave/internal/config --exec /mnt/d/RunWeave/bin/p1-config-linux-amd64.test '-test.timeout=30s'
wsl -d Ubuntu --exec /mnt/d/RunWeave/bin/p1-cli-linux-amd64.test '-test.v' '-test.timeout=60s'
wsl -d Ubuntu --exec /mnt/d/RunWeave/bin/runweave-linux-amd64 version
```

WSL 使用获准的系统权限访问；测试数据库/秘密在原生 Linux 临时目录生成并清理，没有测试跳过的权限负例。最终 version 实际为 `0.0.1-dev`、stage `p1-identity`。
