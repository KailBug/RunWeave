# P0 真实客户端验证指南

状态：现行。日期：2026-09-11。适用范围：Windows PowerShell / Go 1.27.0 / Codex CLI 0.153.4；内存契约探针。维护责任：当前工作项开发者。

## 前提与准备

工作目录为仓库根目录 `D:\RunWeave`。需要已有 Codex CLI 安装与有效登录、可访问模型服务、Go 锁定依赖。此次均已满足，无须用户提供 token、配置 Node、准备真实数据或修改全局 MCP 配置。运行会使用当前 Codex 账户额度。沙箱内凭据不可读时可能错误显示未登录，应在已有授权的系统环境检查 `codex login status`，不要因此重置凭据。

探针只读写合成内存数据，审计仅写指定的新文件；stdout 专用于 MCP。内存 ID 在进程退出后失效。边界与字段见[MCP 工具参考](../参考/MCP工具.md)。

```powershell
$env:GOPATH = "$PWD/.cache/gopath"
$env:GOMODCACHE = "$PWD/.cache/gomod"
$env:GOCACHE = "$PWD/.cache/gobuild"
go build -o bin/mcp-contract-probe.exe ./cmd/mcp-contract-probe
./bin/mcp-contract-probe.exe check
go test ./... -count=1
go vet ./...
```

逐条检查退出码。check 经 SDK 启动真实 stdio 子进程，但不调用模型；它不能替代下一节的外部客户端验收。schema 更新时用 `schemas` 子命令导出 UTF-8 到 `docs/资源/MCP契约/tools.json`，相关快照/证据测试不能通过修改预期掩盖不兼容。

## 启动真实客户端

下列命令使用全新的证据目录；已有审计文件会因 O_EXCL 拒绝覆盖。按实际复验日期更换目录，并同步命令里的三处路径。临时目录置于 `.cache`，不触碰用户项目内容。客户端未指定模型，不写全局配置，仅在本次进程中配置和准许这一组六个已审阅的内存工具；shell 仍处于 read-only 沙箱。

```powershell
New-Item -ItemType Directory -Force .cache/p0-real-client-20260911 | Out-Null
Get-Content -Raw 'D:/RunWeave/docs/资源/MCP契约/客户端验证提示.txt' |
  codex exec --json --ephemeral --ignore-user-config -s read-only `
  --skip-git-repo-check -C D:/RunWeave/.cache/p0-real-client-20260911 `
  -c 'mcp_servers.runweave_contract.command="D:/RunWeave/bin/mcp-contract-probe.exe"' `
  -c 'mcp_servers.runweave_contract.args=["serve","--audit","D:/RunWeave/.cache/p0-real-client-20260911/audit.jsonl"]' `
  -c 'mcp_servers.runweave_contract.required=true' `
  -c 'mcp_servers.runweave_contract.default_tools_approval_mode="approve"' `
  - > .cache/p0-real-client-20260911/client.jsonl `
  2> .cache/p0-real-client-20260911/client.stderr.txt
```

本次上述命令已实测。退出码应为 0，JSONL 应有 turn.completed，且 13 个实际 mcp_tool_call 完成事件；其中三个预期业务错误在 Codex 中标为 failed，服务端 isError=true，不表示整个测试失败。客户端的自然语言总结不作为通过证据。

## 证据核对与退出

对照客户端 MCP 完成事件与服务端 audit 的 initialize、tools/list、tools/call：核验六个名称与全部 schema；13 次调用的顺序、参数、structuredContent/文本相同；重复请求 ID/摘要、冲突错误、审批、取消意图/确认、有界产物及缺失错误符合提示。只保存 MCP 事件和服务端协议记录，剔除会话 ID、模型回复、账户用量等无关信息；认证文件和完整用户配置不入库。

本次脱敏文件位于[证据目录](../资源/MCP契约/README.md)，`go test ./internal/contractprobe -run TestRecordedCodexEvidence -v` 可离线重核。修改证据时必须来自一次新的真实运行，不能生成期望记录冒充事件。该测试验证已保存事实的一致性，不是重新调用模型。

进程正常退出会关闭 stdio 与内存探针，无需撤销 Node 或修改配置。复验使用新缓存目录，旧缓存可由维护者按需清理。遇到认证/网络错误先检查 stderr；没有真实工具事件则保持未通过。MCP 无法启动时核对二进制、审计目标目录和文件是否已存在；只调整本次进程配置，不自动放开全局沙箱或其他工具。
